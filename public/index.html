16 & 17. Rekomendasi Arsitektur & Keamanan Produksi

Arsitektur Multi-Tenant Cloudflare Pages + D1 SQLite + R2

Sesuai spesifikasi bahwa penyimpanan lokal browser tidak cukup untuk platform multi-pengguna yang diakses oleh ratusan hingga ribuan tamu di berbagai perangkat, paket produksi aplikasi ini memisahkan 3 lapisan utama:

1. Frontend & PWA

HTML5 Modular, Tailwind CSS, Service Worker Offline-First, & Kompresi Gambar Otomatis sebelum unggah.

2. API & Keamanan

Cloudflare Pages Functions (`functions/api/*`), PBKDF2 SHA-256 Password Hashing, Sanitasi XSS, & Rate Limiting.

3. Database & Media

Cloudflare D1 (SQLite terdistribusi gratis hingga 5GB) & Cloudflare R2 untuk foto/MP3 tanpa biaya bandwidth keluar.

Backup & Restore Seluruh Data Platform

Ekspor seluruh data pasangan pengantin, kustomisasi tema, daftar tamu, dan RSVP ke file JSON untuk pencadangan berkala atau migrasi server.
